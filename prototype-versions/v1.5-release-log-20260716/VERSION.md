- 版本定位：将固件生命周期收敛为聚焦关键结果的发布日志

## 核心能力

1. Tab 名称调整为“发布日志”，不再表达无法覆盖的完整固件生命周期。
2. 日志数据仅包含钉钉审批、版本生效、DING 结果和回滚记录。
3. 顶部只保留当前发布、历史发布和历史回滚三个关键指标。
4. 批次列表只展示版本变化、批次状态、审批结果、DING 结果、时间和详情入口。
5. 删除待审批指标、阶段筛选、结果筛选、事件明细表及批次内事件展开。
6. 详细事件仅在“发布日志详情”抽屉中展示一次，不再重复关联记录和事件编号。
7. DING 失败与版本生效状态解耦，当前阶段不提供重试或补发入口。
