# v1.39 固件必配功能自动配置

- 日期：2026-07-30
- 状态：可评审
- 上一版本：`v1.38-ai-translation-content-fix-20260730`

## 本次变更

- 新增固件版本时，按所属产品线自动加载全部固件必配功能。
- 编辑旧版本时保留已有必配版本，并自动补齐缺失的必配功能。
- 必配功能不展示复选框、不允许移除，但可切换其他已发布版本。
- 全选、取消全选与已选数量仅作用于可选功能。
- 保存版本和发布前增加必配功能完整性与版本可用性校验。
- 同步更新页面需求打点与本期产品需求方案。

## 验证范围

- 新增版本默认显示当前产品线全部必配功能。
- 功能弹窗区分必配与可选功能，必配项无复选框。
- 全选和取消全选不影响必配功能。
- 必配功能可更换版本但不可删除，可选功能可添加和移除。
- 编辑缺少必配功能的旧版本时自动补齐。
- 保存及发布校验能够阻止必配功能缺失或版本失效。

## 恢复方式

使用本目录的 `index.html`、`app.js`、`styles.css`、`assets/` 和 `产品文档/` 可完整恢复本版本。
