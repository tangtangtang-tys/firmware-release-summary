# 固件发布原型 v1.40

本快照封存新增与编辑固件版本页面的体验优化版本，可用于评审或恢复。

## 核心变化

- 单页三段式布局：固件包与适用范围、功能配置、发布说明。
- 固件包解析结果集中展示，编辑页保持只读。
- 适用机型从固件标识绑定范围中选择，并兼容历史原值。
- 功能配置统一入口，必配功能自动加载，可选功能按需添加。
- APP 更新说明默认聚焦简体中文，支持从平台说明生成和 AI 多语言翻译。
- 修改后通过关闭、取消、遮罩或 Esc 退出均需二次确认。

打开 `index.html#/firmware` 后进入固件列表，点击“新增版本”或非当前版本的“编辑”进行评审。
