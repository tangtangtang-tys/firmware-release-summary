## 核心变更

1. 固件版本列表仅当前正式发布版本不展示“发布”，其他状态均展示发布入口。
2. 未发布、历史发布和已撤回版本均可重新提交发布审批。
3. 发布审批中的目标版本点击“发布”进入已有审批，不重复创建审批单。
4. 存在其他发布或回滚审批时保留入口，点击后提示并发冲突。
5. 历史或已撤回版本审批驳回、失效后恢复提交前状态。
6. 发布、编辑和删除继续独立判断；重新发布不放开历史及已撤回版本的删除权限。
