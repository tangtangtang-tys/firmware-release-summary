- 封存时间：2026-07-16

- 版本定位：发布批次内联展开关键时间节点链路

## 核心能力

1. 点击发布批次摘要直接展开或收起时间节点，不再打开详情侧栏。
2. 默认展开当前生效批次，多个批次可独立展开和收起。
3. 节点按时间正序展示提交审批、审批结果、版本生效或回滚生效、DING 结果。
4. 搜索命中批次任一节点时仍保留该批次完整链路。
5. 保持精简边界，不恢复事件明细表、APP 分发、设备执行、DING 重试或补发。
6. 修正历史发布统计口径，并补齐后续发布与回滚的批次状态联动。

## 验证结果

- JavaScript 语法检查通过，84 个静态操作入口均有对应处理分支。
- 桌面端显示 3 个发布批次，默认仅展开当前生效批次的 4 个关键节点。
- 展开历史批次后不生成抽屉，批次之间的展开状态互不影响。
- 搜索审批人可命中关联批次，同时保留该批次未直接命中的上下文节点。
- “历史发布”由重复计算当前发布的 2 次修正为 1 次。
- 390px 窄屏无页面级横向溢出，时间节点内容无内部溢出。
- 浏览器控制台无本地应用错误。
