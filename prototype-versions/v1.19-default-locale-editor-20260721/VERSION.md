# 原型版本 v1.19-default-locale-editor-20260721

- 封存时间：2026-07-21
- 版本状态：可评审
- 上一版本：`v1.18-edit-permission-audit-20260721`
- 版本定位：九种默认语言与可滚动多语言编辑器

## 核心变更

1. 左侧固定展示九种默认语言：简体中文、英文、意大利语、韩语、德语、日语、法语、俄语和西班牙语。
2. 默认语言统一使用中文名称，Locale 作为辅助信息。
3. 左侧语言列表固定高度、独立纵向滚动，选择底部语言后自动保持可见。
4. 简体中文和英文必填；其余默认语言选填并区分“未配置/已配置”。
5. 空的选填语言不写入版本数据和审批快照，APP 使用英文说明兜底。
6. 配置状态和“已配置 X / 9”数量随输入实时更新。
7. “添加语言”用于增加默认范围外的 Locale；默认语言不可删除，扩展语言可以删除。
8. 新增/编辑版本与当前版本文案维护入口使用相同编辑器和校验规则。

## 验证结果

- JavaScript 语法及 Git 差异格式检查通过。
- 九种默认语言名称、Locale 和固定顺序正确。
- 左侧可滚动区域 `clientHeight=358`、`scrollHeight=502`，可定位至西班牙语。
- 西班牙语输入后实时由“未配置”变为“已配置”，数量由 `2 / 9` 变为 `3 / 9`。
- 空选填语言允许保存且不会写入版本数据。
- 清空英文会阻止保存，自动定位 `en-US` 并显示必填错误。
- 当前版本文案维护弹窗同步展示九种默认语言和修改原因。
- 页面无全局横向溢出，浏览器控制台无应用错误。
