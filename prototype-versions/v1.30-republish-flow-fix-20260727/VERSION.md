# v1.30 下架后重新发布链路修复

- 版本：`v1.30-republish-flow-fix`
- 日期：`2026-07-27`
- 状态：可评审
- 上一版本：`v1.29-current-version-delisting-20260723`

## 本版范围

- 暂无当前发布版本时，提供独立版本选择弹窗，最近下架版本置顶并默认选中。
- 顶部版本选择与列表行内发布统一复用发布资格、审批并发和 APP 文案校验。
- 修复版本表“更新时间”和“操作”列错位造成操作入口不可见的问题。
- 修复下架后当前版本空值形态不一致，导致重新发布审批通过被误判失效的问题。
- 审批成功时间节点仅在状态复检通过后写入，避免成功与失效日志冲突。
- 操作日志、审批日志默认使用动态近 7 天范围，确保新记录默认可见。

## 已验证链路

`暂无当前发布版本 → 选择最近下架版本 → 配置 APP 弱提醒 → 提交发布审批 → 模拟审批通过 → 版本成为唯一当前发布版本 → 发布日志、审批日志、操作日志同步留痕`

## 恢复方式

需要回退时，将 `prototype-versions/v1.29-current-version-delisting-20260723/` 中的 `index.html`、`app.js`、`styles.css` 和 `assets/` 恢复到原型根目录。恢复本版本时，使用本目录中的同名文件覆盖原型根目录。
