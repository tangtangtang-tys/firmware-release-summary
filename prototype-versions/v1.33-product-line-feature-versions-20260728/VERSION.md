# v1.33 产品线功能点版本配置

- 日期：2026-07-28
- 状态：可评审
- 上一版本：`v1.32-remove-version-capabilities-20260728`

## 本次变更

- 功能点来源切换为机型平台功能管理，并按固件标识所属产品线加载。
- 选择功能点后默认配置最新已发布可用版本，支持切换其他已发布版本。
- 测试中、草稿和已停用版本不可用于新固件关联。
- 保存完整功能点版本快照，并同步到版本详情、发布审批和 DING 预览。
- 发布提交和审批通过前复检功能点版本来源状态。
- 版本列表将“功能集数”调整为“功能点数”，历史功能集仍只读保留。

## 验证结果

- JavaScript 语法、Git 差异格式和规则编号唯一性校验通过。
- IPC 产品线仅加载 6 个 IPC 功能点，其他产品线数据不混入。
- 移动侦测默认选择 V2；V3 测试中、V1 已停用且不可选择。
- 夜视模式从最新 V4 切换至其他已发布版本 V3 后可保存。
- 版本列表、详情、审批快照和审批驳回恢复保持一致。
- 390px 窄屏无页面横向溢出，控制台无应用错误。

## 恢复方式

使用本目录的 `index.html`、`app.js`、`styles.css`、`assets/` 和 `产品文档/` 可完整恢复本版本。
