# 原型版本 v1.16-rollback-ding-recall-20260721

- 封存时间：2026-07-21
- 版本状态：可评审
- 上一版本：`v1.15-ding-entry-current-release-20260717`
- 版本定位：回滚不触发 DING，原发布 DING 支持独立撤回

## 核心变更

1. 只有当前生效的正常发布事件可以发送 DING，回滚事件固定显示“不适用”。
2. 原发布 DING 发送中或撤回中时阻止发起回滚，避免通知与版本状态并发冲突。
3. 回滚弹窗只读展示原发布 DING 状态，明确回滚不会自动发送或撤回通知。
4. 回滚审批通过后结果页展示“固件回滚成功、回滚 DING 不触发”。
5. 原发布 DING 仍可撤回时，回滚成功结果提供独立撤回入口；暂不处理后入口继续保留。
6. 撤回流程包含撤回原因、二次确认、撤回中、已撤回和撤回失败状态。
7. 发送状态与撤回状态分别保存；撤回失败允许重试同一消息，不创建新的通知任务。
8. 版本详情同步展示发送结果、撤回状态、接收人快照、时间和操作。
9. 发布日志继续保持只读，回滚链路展示“DING 不适用”和原发布 DING 处理结果。
10. 新增“撤回 DING”权限项，并同步三份产品需求文档。
