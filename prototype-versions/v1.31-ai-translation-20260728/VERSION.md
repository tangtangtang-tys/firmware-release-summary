# v1.31 APP 更新说明 AI 多语言翻译

- 版本：`v1.31-ai-translation`
- 日期：`2026-07-28`
- 状态：可评审
- 上一版本：`v1.30-republish-flow-fix-20260727`

## 本版范围

- 简体中文作为唯一 AI 翻译源，英文作为始终启用且不可取消的 APP 默认兜底。
- 原页面内提供 AI 一键翻译、适配语言范围、逐项确认、全部确认和重新翻译当前语言。
- 固件标识记忆语言范围，历史版本数据兼容迁移为已确认，不因新规则失效。
- 简体中文变化后保留旧译文并标记“需更新”；一键翻译默认保护人工译文。
- 启用语言必须有内容、未超限且已确认，才能保存或进入发布、回滚审批。
- 审批快照只写入启用语言，未启用语言由 APP 使用英文说明。
- 需求批注增加 `LOC-R09` 至 `LOC-R15`，并修复工具栏批注遮挡业务按钮的问题。

## 已验证链路

`编辑非当前版本 → 更新简体中文 → 选择英文/日语/韩语/西班牙语 → AI 一键翻译 → AI 草稿阻断保存 → 全部确认 → 保存 → 重新打开验证持久化 → 修改中文 → 译文标记需更新 → 人工译文受保护 → 显式重译并确认 → 提交发布审批 → 快照仅含 5 种启用语言 → 未启用繁体中文使用英文兜底`

已同时验证 390px 手机端和 1440px 桌面端，无横向溢出，浏览器控制台无应用错误。

## 恢复方式

需要回退时，将 `prototype-versions/v1.30-republish-flow-fix-20260727/` 中的 `index.html`、`app.js`、`styles.css` 和 `assets/` 恢复到原型根目录。恢复本版本时，使用本目录中的同名文件覆盖原型根目录。
