# 固件发布原型 v1.44

本快照封存功能配置视觉精简与发布快照信息补全版本，可用于评审或恢复。

## 核心变化

- 新增与编辑固件版本页的功能配置表仅保留功能名称、配置版本。
- 功能点配置弹窗移除“已自动配置”“可选能力”“固件必配”等重复标签。
- 必配功能仍自动加载、锁定且不可移除；可选功能仍可勾选和移除。
- 功能源或关联版本异常时，错误原因仍在配置版本下就地展示。
- 发布审批功能点快照增加版本说明，并移除重复的审批边界提示条。
- 四列快照在窄屏时仅表格内部横向滚动，不撑开页面。

打开 `index.html#/firmware` 后，分别进入版本编辑、功能配置弹窗和发布审批弹窗进行评审。
