# 原型版本 v1.2-differential-package-20260715

- 封存时间：2026-07-15
- 版本状态：可评审
- 上一版本：`v1.1-product-iteration-20260715`
- 版本定位：补齐 4G 模组在线差分与差分包管理完整交互

## 核心能力

1. 仅 4G 模组固件标识展示“在线差分”和“差分包列表”两个扩展 Tab。
2. 在线差分支持名称搜索、状态过滤、新增任务、目标版本和多源版本配置。
3. 差分任务创建后同步生成任务明细与对应差分包模拟数据。
4. 任务详情展示源版本、目标版本、模组型号、差分状态、失败原因和下载操作。
5. 差分包列表支持目标版本搜索、汇总展开、下载与删除。
6. 删除差分包包含取消和确认分支，确认后数量、明细和空状态同步更新。
7. 角色权限补充差分查看、新建、下载和删除能力。

## 验证结果

- JavaScript 语法检查通过，浏览器控制台无错误。
- IPC 等非 4G 产线不显示差分 Tab，4G 模组显示 3 个 Tab。
- 新增任务必填校验、创建成功、状态过滤和详情抽屉通过。
- 差分包展开、下载、删除取消、删除确认和空状态通过。
- 390px 移动视口无页面级横向溢出，长表格在容器内滚动。
- 已恢复干净的演示数据，未保留回归测试任务。
