# 固件发布平台本期版本用户操作手册

> 适用版本：当前本期迭代原型
>
> 说明：本手册不包含“审批配置”模块的维护操作，仅说明固件发布业务、日志、用户与角色等使用方式。
>
> **审批口径更新（2026-10-24）**：审批以《多级审批发布回滚下架_需求迭代范围与业务闭环_V1.0.md》V1.3 为准。平台审批中心负责创建、处理和留痕，钉钉仅发送通知；本文中“提交钉钉审批”等历史表述不代表钉钉承载审批决策。

## 一、版本范围

### 1. 本期包含的功能

1. 固件标识维护：新增、查询、编辑、删除。
2. 固件版本维护：上传固件包、新增版本、编辑非当前版本、删除未发布版本。
3. 功能项配置：按产品线加载必配和可选功能项，配置功能版本。
4. APP 更新说明：维护 15 种语言，支持 AI 翻译、人工确认、英文兜底和文案修订记录。
5. 固件正式发布：选择版本、配置 APP 提醒方式、提交平台审批中心审批并执行发布。
6. 当前版本回滚：对当前发布版本恢复唯一前序版本，并提交平台审批中心审批。
7. 当前版本下架：提交下架审批，审批通过后进入“暂无当前发布版本”。
8. 发布日志：按时间线查看发布、回滚、下架和审批结果。
9. 4G 模组在线差分：创建差分任务、查看差分结果。
10. 4G 模组差分包：查看、下载和删除差分包。
11. 模组型号：查询模组、SOC、关联固件和 FOTA 工具信息。
12. 操作日志、审批日志：查询关键操作、审批节点和执行结果。
13. 用户列表、角色权限：维护平台用户状态、产线范围、角色及角色功能权限。

### 2. 本期不包含的功能

- 审批方案配置、审批级数和审批节点维护。
- 固件测试升级、灰度发布、放量策略。
- 设备升级结果、成功率和设备侧重试统计。
- APP 分发结果或用户点击升级结果。
- 任意历史版本回滚和系统自动回滚。
- 已保存固件包的替换；需要更换固件包时请新建版本号。
- 一键复制已撤回版本。

## 二、页面导航

左侧菜单分为三组：

### 1. 设备固件

- **固件列表**：维护固件标识、固件版本、发布、回滚、下架和 4G 差分。
- **模组型号**：查询模组型号与关联固件。

### 2. 日志管理

- **操作日志**：查询平台写操作及成功、失败、阻止原因。
- **审批日志**：查询发布、回滚、下架审批及执行结果。

### 3. 系统管理

- **用户列表**：查询用户、产线、账号状态和角色，维护用户权限范围。
- **角色权限**：新增自定义角色，维护角色权限和查看关联用户。

## 三、通用操作规则

1. 页面上的操作入口会同时受到角色权限、所属产线、版本状态和审批并发锁控制。
2. 审批期间目标版本会锁定，不能编辑、删除或重复提交新的审批。
3. 版本号和已保存固件包不可修改；版本内容变更通过递增记录版本号保存。
4. 列表支持分页；复制按钮用于复制下载地址，下载按钮用于下载固件或差分包。
5. 查询条件输入后按 **Enter** 或点击“查询”生效；日期范围的开始日期不能晚于结束日期。
6. 页面提示“无权限”“版本已锁定”或“审批冲突”时，应先处理对应状态，不要重复点击提交。

## 四、固件列表操作

### 1. 查询固件标识

1. 进入“设备固件 > 固件列表”。
2. 在顶部选择“所属产品线”。
3. 在搜索框输入固件标识或版本号，按 **Enter**。
4. 左侧选择目标固件标识，右侧显示该标识的版本和发布信息。

页面顶部会展示所属产线、创建时间、关联机型、去重后的绑定设备数、网络类型、电量类型和架构类型。

### 2. 新增固件标识

1. 点击“新增标识”。
2. 填写固件标识，格式为三个数字段，例如 `23.110.211`。
3. 选择所属产品线。
4. 填写关联机型。
5. 点击“确认”。

注意：固件标识创建后，关联机型不可二次编辑；固件标识不能与已有标识重复。

### 3. 编辑固件标识

1. 选中固件标识，点击右侧“更多 > 编辑”。
2. 可调整所属产品线、网络类型、电量类型和架构类型。
3. 固件标识和关联机型为只读信息。
4. 点击“保存”。

### 4. 删除固件标识

1. 选中固件标识，点击“更多 > 删除”。
2. 确认删除范围后提交。

删除限制：至少保留一个固件标识；仍被模组型号关联的标识不可删除，请先解除关联。

## 五、固件版本维护

### 1. 新增固件版本

1. 在目标固件标识下点击“新增版本”。
2. 上传 `.bin` 或 `.binpkg` 固件包。
3. 等待系统解析版本号、MD5 和文件大小。
4. 选择适用机型并填写“平台发布说明”。
5. 点击“配置功能项”，确认必配功能和可选功能。
6. 填写 APP 更新说明，至少完成简体中文和英文。
7. 点击“创建版本”。

保存后版本状态为“未发布”。固件包解析失败、文件为空、版本号与当前固件标识不匹配时不能保存。

### 2. 功能项配置

1. 功能项来源于当前固件标识所属产品线的机型平台功能管理。
2. 必配功能项由系统自动加载，不能删除；可以更换其配置版本。
3. 可选功能项可以搜索、按分类筛选、批量选择或移除。
4. 功能版本可选择“已发布”或“测试中”版本。
5. 测试中版本仅用于 OTA 指定设备验证，不能直接通过正式发布校验。
6. 保存时系统会记录功能项名称、分类、配置版本、版本状态和版本说明快照。

### 3. 编辑非当前版本

1. 在版本列表找到未发布、历史发布、已撤回或已下架版本。
2. 点击“编辑”。
3. 修改适用机型、平台发布说明、功能项配置或 APP 更新说明。
4. 点击“保存并生成 Rn+1”。

编辑限制：当前正式发布版本不可完整编辑；正在审批的目标版本不可编辑；版本号和固件包不可替换。每次保存都会递增记录版本号并保留变更前快照。

### 4. 删除未发布版本

1. 仅对“未发布”版本点击“删除”。
2. 确认删除。

当前发布、审批中、历史发布、已撤回和已下架版本不能删除。

## 六、APP 更新说明

### 1. 语言规则

系统固定支持以下 15 种语言：简体中文、英文、繁体中文、越南语、泰语、日语、韩语、俄语、德语、法语、西班牙语、意大利语、荷兰语、波兰语、葡萄牙语。

- 简体中文和英文为必填语言。
- 其余语言可选，未配置时 APP 使用英文说明兜底。
- 简体中文、繁体中文、日语、韩语最多 80 字。
- 英文及其他语言最多 160 个字符。
- 不允许输入 HTML 或脚本内容。

### 2. 使用 AI 翻译

1. 先填写或修改简体中文源文案。
2. 点击“选择适配语言”，勾选需要生成的目标语言。
3. 点击“AI 一键翻译”。
4. 检查每种语言的 AI 草稿。
5. 逐项点击“确认当前”，或点击“全部确认”。
6. 确认无误后保存版本。

中文源文案修改后，已启用的 AI 译文会标记为“需更新”；人工译文不会被自动覆盖。需要覆盖时，使用对应语言的“重新翻译”，再重新确认。

### 3. 维护当前发布版本文案

1. 打开当前发布版本“详情”。
2. 切换到“APP 更新说明”。
3. 点击“维护文案”。
4. 修改语言内容并填写“修改原因”。
5. 点击“保存修订”。

当前版本的文案维护不需要重新发起固件发布审批，但会生成不可覆盖的文案修订记录，并更新 APP 文案缓存。版本详情的“文案修订记录”会展示操作人、时间、修改原因和修订版本。

## 七、正式发布

### 1. 发起发布审批

1. 在版本列表点击目标版本“发布”，或在暂无当前版本时点击“选择版本发布”。
2. 选择目标版本并确认当前发布版本与目标版本。
3. 选择 APP 提醒方式：不提醒、弱提醒、强提醒或强制提醒。
4. 查看影响设备数、适用机型、功能项和 APP 多语言快照。
5. 在右侧 APP 模拟器切换提醒方式和语言，确认用户看到的效果。
6. 点击“提交发布审批”。

发布前会校验固件包、适用机型、必配功能、功能版本、中文和英文文案、已启用语言及审批并发状态。当前正式版本不能重复发布。

### 2. 审批处理

1. 提交后版本进入“审批中”，提交时的版本记录、功能项、APP 文案和提醒方式被冻结。
2. 审批人按系统管理员维护的审批方案依次处理，发起人不能在发布审批过程中替换审批人。
3. 当前节点通过后，进入下一级串行节点；驳回或发起人撤回后，本次审批结束并释放版本锁；发起人仅在“我发起的”按需催办，系统管理员后台兜底。
4. 审批通过后，系统再次复检当前版本指针和快照；复检通过才执行发布。
5. 发布成功后，目标版本成为唯一当前发布版本，原当前版本转为历史发布。

### 3. 审批结果

- **审批中**：目标版本锁定，当前版本继续生效。
- **审批驳回**：当前版本不变，目标版本恢复提交前状态。
- **审批中未处理**：审批不会自动终止；发起人从“我发起的”点击“催办审批人”，再次通知当前节点未处理审批人，同一节点 30 分钟内最多一次；管理员仅在后台兜底。
- **审批通过、执行失败**：审批结果保留，系统管理员可重试执行或终止并转人工补偿。
- **执行成功**：生成发布事件，可在发布日志和审批日志中追溯。

## 八、回滚当前发布版本

1. 在“当前发布版本”卡片点击“撤销并回滚”。
2. 查看当前版本与唯一回滚目标的版本、机型、功能项和 APP 说明差异。
3. 选择本次 APP 提醒方式。
4. 填写回滚原因。
5. 点击“提交回滚审批”。

回滚目标由当前发布事件唯一确定，不支持手工选择任意历史版本。审批通过后，原当前版本标记为“已撤回”，目标版本恢复为当前发布版本；本次回滚成功后关闭连续回滚入口。回滚不会自动发送公告通知。

## 九、下架当前发布版本

1. 在“当前发布版本”卡片点击“下架”。
2. 选择下架原因类型。
3. 填写具体说明，长度为 10 至 500 个字符。
4. 点击“提交下架审批”。
5. 审批通过后确认下架结果。

下架成功后，系统清空当前发布版本指针，页面显示“暂无当前发布版本”。固件包、历史记录和已升级设备不受影响，已创建的 OTA 任务不由本平台自动停止。下架版本仍可编辑并重新发起发布审批，但不可删除。

## 十、版本详情与发布日志

### 1. 查看版本详情

点击版本列表“详情”，在同一个详情抽屉中查看：

- **功能项配置**：发布时冻结的功能名称、分类、配置版本、版本状态和版本说明。
- **APP 更新说明**：当前保存的语言文案和文案修订记录。
- **发布记录**：版本发布、回滚、下架等生效或退出记录。
- **审批日志**：与该版本关联的审批类型、节点链路、审批状态和执行状态。

详情抽屉中的页签切换不会离开当前版本。

### 2. 查看发布日志

1. 在固件列表切换到“发布日志”。
2. 使用“搜索版本号或操作人”定位事件。
3. 选择“今天”“近 7 天”“全部”或自定义日期范围。
4. 点击发布事件展开审批、发布生效、回滚生效或下架生效等过程节点。

发布日志为只读审计视图，按日期分组；当前生效事件默认展开，同一时间只展开一条事件链路。

## 十一、4G 模组在线差分

### 1. 创建差分任务

1. 选择“4G 模组”产品线和目标固件标识。
2. 切换到“在线差分”。
3. 点击“差分任务”。
4. 填写差分任务名称，最多 50 个字符。
5. 选择一个目标版本。
6. 选择一个或多个源版本，源版本不能与目标版本相同。
7. 模组型号由固件标识自动带出。
8. 点击“确认”。

任务结果展示状态、成功率、差分包数量、任务完成时间和每个源版本的结果。失败任务不在原任务上重试，需要重新创建差分任务。

### 2. 查看和下载差分包

1. 切换到“差分包列表”。
2. 按目标版本查看差分包分组。
3. 点击展开按钮查看源版本、差分包大小和包名称。
4. 点击“差分包下载”。

### 3. 删除差分包

1. 在差分包明细中点击“删除”。
2. 阅读影响提示并二次确认。

删除后，该差分包不能再被后续 OTA 任务选择；已经创建的任务不受影响。

## 十二、模组型号

1. 进入“设备固件 > 模组型号”。
2. 输入模组型号或 SOC 型号，按 **Enter** 查询。
3. 查看模组型号、SOC、关联固件数、FOTA 工具版本、配置文件和创建时间。
4. 点击“关联固件数”可查看该模组关联的固件标识、所属产线和关联时间。

## 十三、操作日志与审批日志

### 1. 操作日志

1. 进入“日志管理 > 操作日志”。
2. 输入固件版本号，或选择开始日期和结束日期。
3. 点击“查询”；需要恢复默认条件时点击“重置”。
4. 查看操作时间、操作人、角色、模块、动作、资源、结果和事件描述。

操作日志会记录版本新增、编辑、删除、发布、回滚、下架、差分、权限和用户变更，以及被权限、状态或审批锁阻止的操作。

### 2. 审批日志

1. 进入“日志管理 > 审批日志”。
2. 按固件版本号和提交日期查询。
3. 查看审批类型、所属产线、策略版本、提交人、当前审批人和节点级数。
4. 查看审批状态与执行状态。
5. 点击“详情”查看审批快照、串行节点、人工催办记录、审批结果和执行结果。

审批日志中的节点为提交时快照；发布审批人不能在途替换。回滚和下架审批同样以提交时审批人快照为准，本期不支持重新分派或临时代理；可按需人工催办。

## 十四、用户列表

### 1. 查询用户

1. 进入“系统管理 > 用户列表”。
2. 输入账号名称或角色，按 **Enter** 或点击“查询”。
3. 使用所属产线筛选按钮选择一个或多个产线。
4. 点击“重置”恢复默认列表。

### 2. 查看用户详情

点击“详情”，查看账号名称、用户 ID、角色、账号状态、所属产线标签、创建时间、备注、角色权限和变更日志。

用户详情中的所属产线仅以标签展示，不通过详情页二次选择审批资格。

### 3. 维护用户权限

1. 点击“权限配置”。
2. 修改账号状态、所属产线、备注和关联角色。
3. 查看角色权限预览。
4. 点击“完成”。

停用用户不能被新审批方案选择；若用户仍承担进行中的发布审批节点，不能停用或移除对应产线。发布审批在途不支持替换审批人。

## 十五、角色权限

### 1. 新增自定义角色

1. 进入“系统管理 > 角色权限”。
2. 点击“新增角色”。
3. 填写角色名称、角色编码和备注。
4. 保存后，在角色列表中选择新角色。

### 2. 编辑角色权限

1. 选择自定义角色。
2. 点击“编辑权限”。
3. 按菜单、页面和功能操作勾选或取消权限。
4. 点击“保存权限”。

权限生效前按“页面权限 → 功能操作权限 → 数据范围 → 版本状态 → 审批并发锁”顺序校验。系统管理员专属操作不能授予普通角色。

### 3. 查看关联用户

1. 选择角色后切换到“关联用户”。
2. 可按所属产线筛选用户。
3. 查看账号名称、所属产线和备注。

### 4. 删除自定义角色

1. 选择没有关联用户的自定义角色。
2. 点击“更多 > 删除”。
3. 确认删除。

仍有关联用户的角色不能删除，请先在用户权限中调整关联角色。系统默认角色不可删除。

## 十六、常见问题处理

| 页面提示 | 处理方式 |
| --- | --- |
| 当前正式发布版本不可完整编辑 | 进入版本详情，在“APP 更新说明”中使用“维护文案”入口 |
| 该版本正在审批，审批快照已锁定 | 等待审批结束、驳回或撤回后再编辑；审批中可按需催办 |
| 只有未发布版本可以删除 | 只能删除尚未形成发布事实的版本 |
| 当前固件标识已有发布、回滚或下架审批 | 先处理已有审批，不重复提交 |
| 缺少有效的中英文 APP 更新说明 | 补齐简体中文和英文并检查字数限制 |
| 测试中功能版本不能发布 | 将功能项切换为已发布版本后再提交审批 |
| 当前没有可用的一次性回滚目标 | 只能对有唯一前序发布版本的当前事件执行回滚 |
| 当前没有可下架的正式发布版本 | 先确认该固件标识存在当前发布版本 |
| 该角色仍关联用户，不能删除 | 先调整用户关联角色，再删除角色 |
| 开始日期不能晚于结束日期 | 修改日期范围后重新查询 |

## 十七、操作结果与审计留痕

以下关键动作均会形成操作日志或审批日志：

- 固件标识新增、编辑、删除。
- 固件版本新增、编辑、删除及记录版本递增。
- APP 文案维护、文案修订记录生成。
- 发布、回滚、下架审批提交、通过、驳回、撤回、催办和执行结果。
- 角色新增、编辑、删除、权限保存。
- 用户状态、产线、角色和备注变更。
- 在线差分任务创建、差分包下载和删除。

遇到业务争议时，优先通过版本详情、发布日志、审批日志和操作日志按版本号进行交叉核对。
