## 核心变更

1. 当前正式发布版本禁止完整编辑；审批目标版本锁定审批快照。
2. 未发布、历史发布和已撤回版本允许编辑元数据，版本号和固件包保持不可变。
3. 编辑保存递增 `recordVersion`，发布和删除继续使用独立状态规则。
4. 权限树与左侧导航统一，并为七类角色配置差异化模拟权限和数据范围。
5. 操作日志补充操作人角色、结果和业务描述，审批日志补充发布、回滚及异常状态。
6. 用户详情补充角色和数据范围变更记录。
7. 新增版本编辑、角色权限与审计闭环流程文档。
